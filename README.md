# השקעה ממבט ראשון

משחק זיהוי דגלים בהשקעות עבור הרשות לניירות ערך. אפליקציית ווב בעברית, מימין לשמאל, בלי שרת ובלי איסוף מידע. רענון הדף מתחיל סיבוב חדש.

השם **השקעה ממבט ראשון** מוגדר במקום אחד: `src/config/gameConfig.ts`, בשדה `gameName`.

## הרצה

```bash
npm install
npm run dev
npm test
npm run build
npm run preview
```

הכתובת המקומית היא `http://127.0.0.1:5173`.

## תוכן

מקור התוכן הוא `isa_swipe_game_content.json` בשורש הפרויקט. האפליקציה מייבאת אותו ולא שומרת עותק. אין לשנות את הניסוח, את הדגלים או את שגיאות המקור בלי אישור מערכת. רשימת הערות נמצאת ב־`EDITORIAL_QA.md`.

שדות חובה בכל פרופיל: `id`, `name`, `age`, `flag` (`red` או `green`), `difficulty` (`easy`, `medium` או `hard`), `tagline`, `bio`, `openingMessage`, `explanation`, `image`. `customFeedback` רשות. `image: null` מציג מציין מקום ממותג, בלי תמונת פנים מומצאת.

כדי לחבר תמונה מקומית:

1. שמים קובץ ב־`public/profiles/`, למשל `public/profiles/nadav.jpg`.
2. מעדכנים את השדה ל־`"image": "nadav.jpg"`. נתיב שמתחיל ב־`/` או בכתובת מלאה נטען כמו שהוא.

## אורך הסיבוב והקושי

כל סיבוב הוא 5 פרופילים. הכרטיס הראשון תמיד קל. כל זיהוי נכון מעלה את הכרטיס הבא: אחרי הצלחה אחת מגיע בינוני, ואחרי שתי הצלחות ומעלה קשה. פספוס לא מוריד רמה שכבר הושגה. אם נגמרו הכרטיסים ברמה המבוקשת, נבחר הכרטיס הקרוב ביותר שנשאר. אין חזרה על פרופיל בתוך הסיבוב.

ב־`src/config/gameConfig.ts`:

- `roundLength: 5` הוא אורך הסיבוב. ערך גבוה מהמאגר ישחק עד שייגמרו הפרופילים.
- `shuffleProfiles: false` שומר על סדר הקובץ בתוך כל רמת קושי, לבדיקות.

במצב פיתוח בלבד אפשר גם:

- `?shuffle=0` לסדר המקור
- `?limit=10` לאורך סיבוב
- `?id=profile-10` לפרופיל אחד

## עיצוב

הטוקנים ב־`src/styles/tokens.css`. המיפוי שם מפנה לעמודי ספר המותג: פלטה, כללי צבע וטקסט, טיפוגרפיה, לוגו, גריד, צורות, פטרן ואייקונים.

הפונט הרשמי הוא סימפלר (Simpler Pro, המשקל הרגיל והמודגש). הקבצים נטענים מ־`public/fonts`. Assistant ו־Alef נשארים גיבוי בלבד. פירוט הרישיונות ב־`public/fonts/NOTICE.txt`.

שמאלה על המסך הוא דגל אדום / לא הטייפ שלי. ימינה הוא דגל ירוק / שווה להכיר. אותו דבר בחיצי המקלדת. דגל ירוק הוא סימן חיובי בסיפור, לא אישור להשקעה.

## מה עדיין חסר

- אישור סופי לאיורי הפרופיל. כרגע לכל 22 הפרופילים יש איור קו בסגנון ספר המותג, ב־`public/profiles`.
- בחירת לוגו למשחק. הכיוון שנבחר הוא 02, המילה על שני הקלפים, והטיוטה המעודכנת ב־`/logo-options.html`. הלוגו הרשמי של הרשות לא שונה.
- ערך מספרי למרווח סביב הלוגו לא הופיע כטקסט בספר המותג. הלוגו נשמר כיחידה, בלי מתיחה או שינוי צבע.
- כוכבית המותג שסופקה צבועה `#0082ff`, לא `#3781ff`. הקובץ משמש כמו שהוא.
- אישור מערכת להערות ב־`EDITORIAL_QA.md`.
